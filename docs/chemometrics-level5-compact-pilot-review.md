### Optional reproducibility material

N05, N06 and N08 show their experiment/result without running R. **Experiment
details / R** opens full editable source and its authored function glossary inside
the same navigable scene. Escape returns to the main view, including from the
editor. The existing local webR runtime remains lazy until Run. Slide printing
omits code; the script/self-study and canonical static fallback retain it. Opening
details does not create another slide or duplicate the source in application JSON.

The adapter's composition, fit and content budget do not count optional code as
main-stage material. `cd:optionalCode` is code-only; it cannot hide a displayed
formula or its required visible legend. See ADR-0025.

### Interval semantics and consistency

The two-threshold state uses the original twenty readings. At most 10.20 includes
15; at most 9.80 includes four; strictly greater than 9.80 and at most 10.20 includes
11, or 55%. Lower-endpoint ties are excluded together. Upper-endpoint ties are
included together. One-threshold mode, reset and invalid-bound feedback retain the
same data. The shaded horizontal range is explicitly not area under the ECDF.

### Normal simulation states

N08 is a **new assumed simulation**, not an extension of the fictional warm-up or
six-result vignette. Mean 10.00 mg/L and SD 0.10 mg/L are not estimated from them.
The Park-Miller seed 20261102 and inverse-normal transformation are unchanged from
the original normal workbench. Independent Python replay confirms every published
bin for prefixes 20, 50, 100 and 1,000. The final state reuses the existing
`ex:nn-growth-data` rather than copying it.

State changes update counts, density bars, n readout, caption, active-state identity
and accessible fallback. Both axis scales and the bin grid stay fixed. Published
counts are never reconstructed as midpoint observations or rebinned. This is a
deterministic saved experiment, not a fresh-randomness claim. Normality and
independence are explicitly generating assumptions. See ADR-0026.
