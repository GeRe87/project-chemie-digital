# Product vision

## Vision statement

Create a knowledge-first platform for chemistry education in which scientific concepts, reusable learning resources, didactic relations, and narrative paths are represented semantically. Presentation slides are generated views, not the primary source of truth.

## Core model

### Knowledge layer

Contains concepts, definitions, mathematical expressions, symbols, examples, exercises, sources, datasets, misconceptions, and scientific relations.

### Didactic layer

Contains learning objectives, prerequisites, activity roles, difficulty, target audience, estimated duration, assessment relations, and learning-path constraints.

### Narrative layer

Defines a specific path for a lecture, pitch, self-study unit, exercise session, review session, or examination preparation.

### Scene layer

Transforms selected resources into bounded presentation or learning states. One path step may generate several scenes.

### Rendering layer

Presents scenes through Reveal.js, a self-study web interface, a knowledge network, print/PDF, or future OER outputs.

## First public demonstration

The first vertical slice is the Studiendekanat pitch. The presentation itself demonstrates the planned platform, including semantic content, a path-driven structure, Reveal.js rendering, and at least one generated knowledge network.
