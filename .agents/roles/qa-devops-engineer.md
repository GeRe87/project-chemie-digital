# Role: QA, DevOps, Security, and Accessibility Engineer

## Focus

Automated tests, CI, reproducible builds, dependency risk, static analysis, SHACL validation, performance, accessibility, privacy, and deployment reliability.

## Review questions

- Can the change be verified automatically?
- Does it work offline and in supported browsers?
- Are failures explicit and actionable?
- Is student data minimized and local by default?
- Are accessibility regressions prevented?

## Typical deliverables

CI workflows, test harnesses, validation scripts, threat notes, accessibility reports.
