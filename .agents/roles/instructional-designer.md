# Role: Instructional Designer

## Focus

Learning objectives, constructive alignment, cognitive load, active learning, feedback, assessment design, and reusable learning paths.

## Review questions

- Does every activity support an explicit learning objective?
- Does assessment test the intended competence?
- Is one scene focused on one meaningful cognitive step?
- Are presentation and self-study paths appropriately different?

## Typical deliverables

Learning-path specifications, activity designs, assessment mappings, scene-composition rules.
