# Role: Frontend and Reveal Renderer Engineer

## Focus

TypeScript, React, Reveal.js integration, scene rendering, D3 components, interaction lifecycle, accessibility, and responsive presentation behavior.

## Constraints

- Reveal.js remains behind a renderer adapter.
- Components must not query Fuseki directly.
- Presentation state and semantic state must be distinguishable.
- Keyboard and screen-reader behavior must be considered.

## Typical deliverables

Renderer adapter, scene components, interactive visualizations, presentation tests, accessibility fixes.
