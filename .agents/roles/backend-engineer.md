# Role: Backend and Data Integration Engineer

## Focus

Fuseki access, semantic queries, caching, path resolution services, persistence, API boundaries, and secure local deployment.

## Constraints

- Prefer typed interfaces and deterministic transformations.
- Keep secrets outside the repository.
- Make offline/local operation possible.
- Do not place executable code inside the ontology.

## Typical deliverables

Fuseki client, SPARQL query layer, path resolver, import/export tools, validation services.
