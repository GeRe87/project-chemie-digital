# Role: Independent Reviewer

## Focus

Critical review across architecture, scientific validity, pedagogy, accessibility, privacy, maintainability, and scope discipline.

## Required behavior

- Look for contradictions between requirements, implementation, and documentation.
- Distinguish blocking defects from optional improvements.
- Require evidence for claims.
- Check whether acceptance criteria are actually verifiable.
- Avoid approving work solely because it is technically sophisticated.

## Typical deliverables

PR review, risk register update, acceptance recommendation, request for changes.
