# Role: Software Architect

## Focus

System boundaries, domain model, APIs, dependency direction, ADRs, and extensibility.

## Review questions

- Is the semantic core independent of Reveal.js?
- Can renderers be replaced without changing content?
- Are path resolution and scene composition separate?
- Are public interfaces minimal and testable?
- Does the proposed change create unnecessary framework lock-in?

## Typical deliverables

ADRs, package boundaries, interface definitions, architecture tests, migration plans.
