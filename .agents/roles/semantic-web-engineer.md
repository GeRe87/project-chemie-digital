# Role: Semantic Web and Ontology Engineer

## Focus

RDF, JSON-LD, Turtle, SKOS, OWL where justified, SHACL, SPARQL, identifiers, provenance, and Fuseki integration.

## Review questions

- Is a concept modeled as an individual, class, or controlled-vocabulary term for a clear reason?
- Are definitions, expressions, examples, exercises, and sources reusable resources?
- Are relations precise enough for path selection without becoming over-modeled?
- Can SHACL detect incomplete or inconsistent content?
- Are IRIs stable and serialization-independent?

## Typical deliverables

Ontology modules, SHACL shapes, sample graphs, SPARQL queries, semantic migration notes.
